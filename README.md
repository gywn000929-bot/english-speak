# Speak Up! 🗣️

회화 중심으로 영문법을 **직접 말하며** 배우는 인터랙티브 학습 웹앱입니다.
세계에서 가장 유명한 영문법 교재 *Grammar in Use Intermediate* 의 유닛 구성을
참고해 만든 **오리지널 학습 콘텐츠**입니다. (교재 원문을 복제하지 않았습니다.)

## 실행 방법

별도 설치 없이 `index.html` 파일을 브라우저에서 열기만 하면 됩니다.
음성 기능(발음 듣기·말하기 채점)은 **Chrome** 에서 가장 잘 동작합니다.

책 전체 커리큘럼인 **145개 유닛 / 16개 파트**를 모두 담았고, 상단 검색창으로 유닛을 빠르게 찾을 수 있습니다.

```bash
# 그냥 파일 더블클릭하거나
open index.html      # macOS
# 또는 간단한 로컬 서버로
python3 -m http.server 8000   # http://localhost:8000
```

## 구성

**145개 유닛 / 16개 파트**, 각 유닛마다 5단계로 학습합니다.

| 단계 | 내용 |
|------|------|
| 📖 설명 | 핵심 개념과 문장 패턴을 한국어 설명으로 |
| 🔊 예문 | 원어민 발음 듣기(TTS)와 함께 예문 익히기 |
| 💬 대화 | 실제 회화에서 어떻게 쓰이는지 대화문으로 |
| ✏️ 퀴즈 | 즉시 채점 + 오답 설명이 나오는 연습문제 |
| 🎤 말하기 | 마이크로 따라 말하면 일치율을 채점 |

**16개 파트**: 현재·과거 · 완료시제 · 미래 · 조동사 · 가정법 · 수동태 · 화법 ·
의문문 · 동사구(-ing/to) · 관사·명사 · 대명사·한정사 · 관계사 · 형용사·부사 ·
접속사 · 전치사 · 구동사

## 빌드

콘텐츠는 `index.template.html`(레이아웃) + 유닛 데이터로 구성되며, `node build.js` 가
데이터를 주입해 최종 `index.html` 을 생성합니다. 배포물은 이 완성된 `index.html` 하나입니다.

## 기능

- **진행률 저장** — 완료한 유닛은 `localStorage` 에 저장되어 다시 열어도 유지됩니다.
- **발음 듣기** — Web Speech API(SpeechSynthesis)로 모든 문장을 원어민 발음으로 재생.
- **말하기 채점** — SpeechRecognition 으로 발화를 인식해 목표 문장과 일치율(%)을 표시.
- **다크/라이트 모드** — 시스템 테마에 맞춰 자동 전환.
- **모바일 대응** — 반응형 레이아웃.

## 기술

의존성 없는 단일 HTML 파일(바닐라 JS + CSS). 빌드 과정이 없습니다.
